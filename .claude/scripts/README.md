# Verificações locais

Rode na raiz do repositório.

- `python3 .claude/scripts/verify.py` executa typecheck, lint e testes do back-end.
- `python3 .claude/scripts/check_tenant.py` verifica o isolamento por restaurante.
- `python3 .claude/scripts/routes_inventory.py` lista as rotas.
- `python3 .claude/scripts/doc_drift.py` compara o código com a documentação.
- `python3 .claude/scripts/repo_map.py` mostra a estrutura do projeto.
- `python3 .claude/scripts/monitor.py --text` consulta a sessão do Claude Code no terminal.
