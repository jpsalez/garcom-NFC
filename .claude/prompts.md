# Modelos de pedido (copie, preencha e cole)

Regra de ouro: um objetivo por pedido, com o que já foi decidido e o formato da resposta.

## Entender / planejar (guia)
```
Quero [objetivo] no módulo [X]. Já decidi: [..]. Me guie: ordem de escrita, regras e erros.
Sem alterar arquivos. Responda em até 300 palavras.
```

## Revisar o que escrevi
```
/revisar back-end/src/modules/[X]
Foque em: tenant, erros e transação. Ignore estilo.
```

## Pedir implementação de boilerplate (explícito)
```
Implemente você: [o que é repetitivo]. Arquivos: [..]. Siga o padrão de [arquivo de referência].
Não toque em mais nada. Depois rode /verificar.
```

## Mostrar como seria
```
Mostre como seria [X] só no chat (não altere arquivos), no meu estilo simples.
```

## Bug
```
Erro: [mensagem exata]. Aconteceu ao [passo]. Arquivo suspeito: [..]. Já tentei: [..].
Explique a causa e me diga o menor ajuste.
```

## Fechar uma tarefa
```
/verificar
Se passar, sugira o commit (mensagem curta) e se preciso rodar /sincronizar-docs.
```
